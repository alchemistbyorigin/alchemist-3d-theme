# Changelog

All notable Alchemist 3D theme changes are documented here.

## [Unreleased]

### Added
- Premium homepage composition with 3D hero, featured products, editorial story, collection showcase, and value strip.
- Global design settings for typography, layout, color, controls, and motion.
- Conditional loading strategy for homepage and 3D assets.
- Accessibility safeguards for visible focus, touch targets, and reduced motion.
- Shopify Theme Check GitHub Actions workflow.

### Changed
- Theme identity updated from Shopify Skeleton Theme to Alchemist 3D.
- 3D hero lifecycle hardened for Theme Editor section load/unload behavior.
- Mobile 3D quality profiles added to reduce rendering cost.
- README and contribution documentation rewritten for the Alchemist 3D project.

### Security / Reliability
- Commercial-release workflow now requires Theme Check and development-store validation.
- Temporary generated theme files are being removed from the release branch.

## [1.0.0] - Planned

First commercial release. Release only after commerce, accessibility, localization, performance, and Theme Editor quality gates pass.
